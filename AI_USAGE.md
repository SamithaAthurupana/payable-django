# AI Usage Declaration

AI tools were used as a development assistant during this technical assessment, as permitted by the assessment instructions.

## How AI Was Used

AI was used to:

- Clarify Django REST Framework concepts.
- Generate initial boilerplate code for serializers, views, and API structure.
- Explain JWT authentication using Django REST Framework SimpleJWT.
- Explain Django transactions (`transaction.atomic`) and row-level locking (`select_for_update`).
- Provide guidance for React Native screen structure and API integration.
- Review code for potential improvements and best practices.

## Manual Work Performed

The final implementation was manually reviewed and adapted to match the assessment requirements.

Manual work included:

- Designing the project structure.
- Implementing business rules for circle membership.
- Enforcing the maximum member limit.
- Implementing sequential member rotation.
- Integrating JWT authentication.
- Debugging backend and frontend issues.
- Testing APIs using Postman.
- Testing the React Native application.
- Adjusting generated code where necessary to satisfy the required functionality.

## Verification

All AI-generated suggestions were reviewed, tested, and modified before being included in the project. The final implementation was executed and verified locally.

## Reflection

AI accelerated development by assisting with explanations and boilerplate code. Understanding the generated code, integrating the components, debugging issues, and validating the final behaviour were completed manually.
